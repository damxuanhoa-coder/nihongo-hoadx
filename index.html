🚀 Cẩm Nang Triển Khai & Cập Nhật Lên GitHub + Vercel

Toàn bộ ứng dụng nằm gọn trong thư mục D:\Google Antigravity\HocTiengNhat. Bạn làm theo đúng các bước sau:

Bước 1: Đưa web lên GitHub lần đầu (5 phút)

1. Mở trang github.com -> Đăng ký / Đăng nhập tài khoản miễn phí.
2. Bấm dấu ➕ (góc trên bên phải) -> Chọn New repository.
3. Ô Repository name gõ: nihongo-mr-dam -> Chọn Public -> Bấm nút xanh Create repository.
4. Ở màn hình tiếp theo, bấm vào dòng chữ xanh uploading an existing file.
5. Mở thư mục D:\Google Antigravity\HocTiengNhat trên máy tính, kéo thả 4 file (index.html, styles.css, data.js, app.js) vào khung trình duyệt -> Bấm nút xanh Commit changes.

Bước 2: Kết nối Vercel để phát sóng Web (2 phút)

1. Mở trang vercel.com -> Bấm Sign Up / Log In -> Chọn Continue with GitHub.
2. Bấm nút Add New... -> Chọn Project.
3. Bạn sẽ thấy kho nihongo-mr-dam hiện ra -> Bấm nút Import bên cạnh nó.
4. Không cần chỉnh sửa gì cả, bấm thẳng nút Deploy!
5. Chờ 15 giây, pháo hoa nổ trên màn hình! Vercel cấp cho bạn đường link vĩnh viễn: https://nihongo-mr-dam.vercel.app.

Bước 3: Cách nạp thêm Bài học, Video, Hình ảnh sau khi đã lên Web

Mỗi khi bạn dùng 2 biểu mẫu bên trái để thêm bài học mới, từ vựng mới hoặc đổi link Video YouTube xong, bạn chỉ cần bấm nút "📥 Xuất File data.js Mới" bên dưới, rồi kéo file data.js đó thả đè lên GitHub. Vercel sẽ tự động cập nhật web cho điện thoại/iPad của con sau 15 giây!
